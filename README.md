# Konstantin Efimidis — Art Portfolio

An independent portfolio website concept for artist Konstantin Efimidis. The site presents a gallery of paintings alongside information about the artist, biography, creative approach, collections, and contact details.

## Project status

**Completed.** The portfolio was built and delivered as a demonstration project. It is not currently hosted or deployed for public access.

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Vite serves the development site at [http://localhost:3000](http://localhost:3000).

To create and preview a production build:

```bash
npm run build
npm run preview
```

## Built with

- HTML, CSS, and JavaScript
- [Vite](https://vite.dev/)
